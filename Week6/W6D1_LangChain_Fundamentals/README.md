\# W6D1: LangChain Fundamentals — Chains \& Prompts



\## 📌 Overview



This project implements the fundamentals of LangChain using Ollama.



The practical tasks include:



1\. LangChain Chain

2\. Conversation Memory

3\. LangChain Agent with two tools



\## 🎯 Learning Objectives



\- Understand LangChain chains.

\- Use PromptTemplate with an Ollama LLM.

\- Parse LLM output using StrOutputParser.

\- Maintain conversation history.

\- Build a simple agent.

\- Use tools with an LLM agent.



\## 🛠️ Technologies Used



\- Python 3.11

\- LangChain

\- LangChain Ollama

\- Ollama

\- Llama 3.2 3B

\- LangGraph

\- Git \& GitHub
