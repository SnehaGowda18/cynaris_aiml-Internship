# W6D5 - Document Chatbot with LangChain

## Objective

Build a simple LangChain-based chatbot demonstrating:

- LangChain chains
- Ollama LLM
- OutputParser
- Conversation memory
- Tool-based agents
- Calculator tool
- Web search stub

## Technologies

- Python
- LangChain
- Ollama
- Llama 3.2
- LangGraph
- VS Code
