# W5D6 – LLM Cost Optimisation

## Objective

This project demonstrates:

- Token counting using tiktoken
- Token cost calculation
- Semantic caching using embeddings
- Cost report generation
- Routing strategy for local vs API LLMs

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

## Output Files

- outputs/token_audit.csv
- outputs/cost_report.txt
- outputs/semantic_cache_results.txt
- outputs/routing_strategy.txt

## Technologies

- Python
- tiktoken
- SentenceTransformers
- NumPy
- Pandas
- Scikit-Learn
