# W5D2 Prompt Engineering & System Prompts with Ollama

## Description

This project demonstrates Prompt Engineering using Ollama.

Different system prompts were used to change the behavior of the same LLM.

The project compares AI responses with and without system prompts.

## Tools Used

- Python 3.11
- Ollama
- Llama3.2 3B
- Requests
- VS Code
- Git
- GitHub
