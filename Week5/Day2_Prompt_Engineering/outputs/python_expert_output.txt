**Reversing a String in Python**
=====================================

Here's an example of a simple function that takes a string as input and returns the reversed string.

```python
def reverse_string(s):
    """
    Reverses a given string.
    
    Args:
        s (str): The string to be reversed.
    
    Returns:
        str: The reversed string.
    """
    return s[::-1]
```

**Explanation:**

This function uses Python's slice notation (`s[start:stop:step]`) to extract the characters from the original string in reverse order. The `[::-1]` part tells Python to start at the end of the string and move backwards, stepping by -1 each time.

**Example Usage:**
```python
original_string = "Hello, World!"
reversed_string = reverse_string(original_string)

print(reversed_string)  # Output: "!dlroW ,olleH"
```

This function is concise, readable, and efficient. However, if you want to implement a solution without using slice notation, here's an alternative implementation:

```python
def reverse_string(s):
    """
    Reverses a given string.
    
    Args:
        s (str): The string to be reversed.
    
    Returns:
        str: The reversed string.
    """
    reversed_s = ""
    for char in s:
        reversed_s = char + reversed_s
    return reversed_s
```

This function uses a simple loop to iterate over each character in the original string, prepending it to the `reversed_s` string. While this solution is more verbose than the slice notation approach, it's still effective and easy to understand.
