# Week 2 Day 4 – Train/Test Split & Cross-Validation

## Objective

Learn how to split a dataset into training and testing sets and evaluate a machine learning model using Cross-Validation.

## Tools Used


# Python
# Pandas
# NumPy
# Scikit-learn
# VS Code / Google Colab

## Concepts Covered

# Train/Test Split
# Logistic Regression
# Model Training
# Model Prediction
# Accuracy Evaluation
# 5-Fold Cross-Validation

## Steps Performed

. Imported the required libraries.
. Created a sample dataset.
. Selected input features and target variable.
. Split the dataset into training and testing sets using `train_test_split()`.
. Trained a Logistic Regression model.
. Predicted the test data and calculated accuracy.
. Performed 5-fold Cross-Validation using `cross_val_score()`.
.Saved the cross-validation scores to the `outputs` folder.
