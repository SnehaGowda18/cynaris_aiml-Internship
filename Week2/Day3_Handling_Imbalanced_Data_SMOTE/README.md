# Week 2 - Day 3
# Handling Imbalanced Data using SMOTE

## Learning Objective

Learn how to handle imbalanced datasets using SMOTE (Synthetic Minority Oversampling Technique) to improve machine learning model performance.

---

## Project Description

This project demonstrates how to balance an imbalanced dataset using SMOTE. The original dataset contains a majority and minority class. After applying SMOTE, synthetic samples are generated for the minority class, resulting in a balanced dataset.
