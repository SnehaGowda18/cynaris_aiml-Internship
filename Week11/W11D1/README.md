# W11D1: MLflow Experiment Tracking

## Description

Implemented MLflow experiment tracking for a RandomForestClassifier using the Iris dataset. Five experiments were conducted with different hyperparameters. The best model was registered in MLflow Model Registry and served using the MLflow model server.

## Tools Used

Python, scikit-learn, MLflow, Git, PowerShell

## Results

Best Accuracy: 96.67%

Registered Model: W11D1-Iris-RandomForest

Version: 1

## MLflow Features

- Experiment tracking
- Parameter logging
- Metric logging
- Model artifact logging
- Model Registry
- Model serving
