# W8D2: RAG Evaluation with Ragas Framework

## Overview

This project implements and evaluates a Retrieval-Augmented Generation (RAG) system using LangChain, ChromaDB, HuggingFace embeddings, Ollama, and the Ragas evaluation framework.

The objective of this task is to measure RAG quality using standard evaluation metrics and optimise the retrieval configuration.

---

## Technologies Used

- Python 3.11
- LangChain
- ChromaDB
- HuggingFace Sentence Transformers
- Ollama
- Llama 3.2 3B
- Ragas
- HuggingFace Datasets
- Git & GitHub
