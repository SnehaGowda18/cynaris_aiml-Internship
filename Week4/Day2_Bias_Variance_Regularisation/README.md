# Week 4 Day 2 – Bias-Variance Tradeoff & Regularisation

## Objective
Learn the concepts of Bias-Variance Tradeoff and Regularisation. Compare Ridge (L2) and Lasso (L1) Regression models, perform hyperparameter tuning using GridSearchCV and RandomizedSearchCV, and evaluate model performance.

---

## Concepts Covered

- Bias-Variance Tradeoff
- Underfitting vs Overfitting
- Ridge Regression (L2 Regularisation)
- Lasso Regression (L1 Regularisation)
- Hyperparameter Tuning
- GridSearchCV
- RandomizedSearchCV
- Model Evaluation (MSE and R² Score)
